# High Fidelity

> High Fidelity provides live spatial audio technology for apps and games — a client SDK and (formerly hosted) Spatial Audio API that simulate natural, positional voice for web and native applications, plus Quad, a spatial social meeting platform. This llms.txt was generated by API Evangelist from the public catalog and repositories.

## Products
- [Spatial Audio SDK (source)](https://github.com/highfidelity/hifi-spatial-audio-js): TypeScript/JavaScript client library (MIT) for integrating spatial audio.
- [Quad](https://www.highfidelity.com/quad): Social platform that recreates physical meeting spaces with spatial audio.

## Packages
- [hifi-spatial-audio on npm](https://www.npmjs.com/package/hifi-spatial-audio): `npm i hifi-spatial-audio` (v2.1.1, MIT).
- [Browser bundle (CDN)](https://hifi-spatial-audio-api.s3-us-west-2.amazonaws.com/releases/latest/HighFidelityAudio-latest.js): Prebuilt HighFidelityAudio web build.
